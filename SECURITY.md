# Security Policy

## Reporting a Vulnerability

If you identify a security issue, do not open a public issue.

Please report privately through GitHub Security Advisories for this repository.
Include:

- reproduction steps
- affected files and paths
- impact assessment
- proposed remediation (if available)

## Scope

This repository treats the following as security-sensitive:

- secrets or token exposure
- unsafe command or shell execution behavior
- machine-local credential leakage
- internal identifier/domain leakage in tracked public files

## Response Targets

- initial triage: within 3 business days
- confirmed issue: prioritized fix and mitigation guidance
- public disclosure: after a fix or safe mitigation is available
